# HUST Computer Architecture Experiments

Course experiments for Computer Architecture at Huazhong University of Science and Technology (HUST).

## Circuits

The `circuits/` directory contains Logisim circuit designs for:

- Computer data representation
- Arithmetic unit design
- Memory-system design
- Single-bus CPU design with modern timing
- MIPS interrupt mechanism with modern timing

## Requirements

Open the `.circ` files with the Logisim-compatible environment used by the course.

## Notes

Personal reports and bundled JAR applications are intentionally excluded.
